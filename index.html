sklearn-contrib-emeans#

EMeans is a scikit-learn compatible implementation of e-means, a mini-batch k-means that typically gets close to the inertia of KMeans in a few passes over the data instead of tens of iterations.

from sklearn_emeans import EMeans

emeans = EMeans(n_clusters=256, n_epochs=5).fit(X)
emeans.cluster_centers_, emeans.labels_, emeans.inertia_
emeans.predict(X_new)

It also fits on a GPU, on PyTorch tensors or CuPy arrays, for instance on the GPU of a Mac:

import sklearn
import torch

X = torch.asarray(X, dtype=torch.float32, device="mps")  # or "cuda", "xpu"
with sklearn.config_context(array_api_dispatch=True):
    emeans = EMeans(n_clusters=256, n_epochs=5).fit(X)
emeans.cluster_centers_  # a tensor on the device of X

This needs SCIPY_ARRAY_API=1 in the environment, see GPU and array API inputs.

Install it with pip install sklearn-contrib-emeans. It needs Python >= 3.10 and scikit-learn >= 1.7.

Relation to scikit-learn#

This is an independent package, not affiliated with scikit-learn or scikit-learn-contrib. Adding EMeans to scikit-learn itself is under discussion in scikit-learn#35383.

Feedback is welcome in the issues, especially on datasets where EMeans does worse than KMeans.
